Components that adapt to the screen and the system theme

Resize the window to see the grid move from one column to two on tablets and three on desktops. Switch your operating system between light and dark to see the colors follow.

Responsive grid

1 column on mobile, 2 from 768 px, 3 from 1024 px.

Tokens first

Colors, spacing, and radii live in CSS custom properties, so dark mode only has to redefine a handful of values.

Mobile first

Base styles target small screens. Media queries add columns as space becomes available.

Keyboard ready

Every interactive element has a visible focus ring and a logical tab order.

No script required

The modal opens and closes with CSS alone, using the :target pseudo-class.

Readable contrast

Text and controls meet WCAG AA contrast in both light and dark themes.

Motion aware

Transitions switch off for people who prefer reduced motion.
